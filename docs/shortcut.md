# iOS 快捷指令配置

服务地址假设为 `https://bitewise.example.com`(替换成你的域名)。所有人用同一个地址,靠各自的令牌区分用户。

## 令牌

每个快捷指令里的 **获取 URL 内容** 都要带上你的令牌(`python -m bitewise add-user <名字>` 生成的那串):

- 展开「头部」,添加一项:键 `Authorization`,值 `Bearer <你的令牌>`(`Bearer` 后有一个空格)。

一个快捷指令里有多次请求时(如「能吃吗」),可以在开头加一个 **文本** 操作写 `Bearer <你的令牌>`,各请求的头部值直接选这个变量。令牌等同密码,不要分享快捷指令的副本给别人;泄露了就删掉 `users.toml` 里该用户的条目,用同一个名字重新 `add-user`(数据按用户名存放,不受影响),再重启服务。

## 快捷指令一:拍照记饭

1. 新建快捷指令,命名「记一顿」。
2. 添加操作:**拍照**(或「从相册中选择」,按喜好;可以两个都建)。
3. 添加操作:**要求输入**(文本,提示语"补充说明(可留空)",允许空输入)。
4. 添加操作:**获取 URL 内容**:
   - URL:`https://bitewise.example.com/api/upload`
   - 方法:`POST`
   - 头部:`Authorization` → `Bearer <你的令牌>`
   - 请求体:`表单`
   - 表单字段:
     - `image` → 类型「文件」,值选「照片」变量
     - `text` → 类型「文本」,值选「提供的输入」变量
5. (可选)添加操作:**显示通知**,内容随意(如"已提交"),确认上传动作跑完了。

建议把它加到主屏幕小组件或锁屏,拍完即传,识别在服务端后台进行,结果去网页看。

## 快捷指令二:文字记录 / 修正 / 体重

1. 新建快捷指令,命名「记一笔」。
2. 添加操作:**要求输入**(文本)。
3. 添加操作:**获取 URL 内容**,同上(含 `Authorization` 头部),但表单只带 `text` 字段。

这一个入口同时支持三种用法,服务端 AI 自动判断意图:

| 输入示例 | 效果 |
|---|---|
| `午饭吃了一碗牛肉面和一个煎蛋` | 记录一顿饭并估算营养 |
| `刚才那顿改成600大卡` | 修改最近的记录 |
| `删掉上一条` | 删除记录 |
| `体重 72.5` | 记录体重(纯体重格式走快速通道,不调 AI) |

## 快捷指令三:能吃吗

吃之前拍一下,AI 结合今天已摄入、剩余额度和你的目标,给出能不能吃、吃多少的建议。咨询本身**不计入**摄入,选「吃了」才记成一顿饭(直接沿用估算结果,不再调 AI)。

1. 新建快捷指令,命名「能吃吗」。
2. 添加操作:**拍照**。
3. 添加操作:**获取 URL 内容**(本快捷指令里的每次请求都带 `Authorization` 头部):
   - URL:`https://bitewise.example.com/api/checks`
   - 方法:`POST`,请求体:`表单`
   - 表单字段:`image` → 类型「文件」,值选「照片」变量
4. 添加操作:**获取词典值**,键 `id`,存为变量 `id`。
5. 添加操作:**重复**(30 次),循环体内:
   1. **等待** 2 秒。
   2. **获取 URL 内容**:`https://bitewise.example.com/api/checks/<id 变量>`(GET)。
   3. **获取词典值**,键 `status`。
   4. **如果** `status` 是 `done`:
      1. 对第 2 步的结果 **获取词典值**,键 `summary`。
      2. **从菜单中选取**,提示语用 `summary` 变量,选项「吃了」「不吃」。
         - 「吃了」分支:**获取 URL 内容** `https://bitewise.example.com/api/checks/<id 变量>/eat`,方法 `POST`;再 **显示通知**「已记录」。
         - 「不吃」分支:留空。
      3. **停止此快捷指令**。
   5. **如果** `status` 是 `failed`:**获取词典值** `error` 并 **显示结果**,然后 **停止此快捷指令**。
6. 循环结束后(约 1 分钟仍未出结果):**显示通知**「还在分析,稍后再试」。

一般 10 秒左右出结果。中途锁屏或切走也没关系,服务端会继续算完;但「吃了」需要在快捷指令里选,错过了就用「记一顿」重新记。

## Dashboard

手机浏览器打开 `https://bitewise.example.com`,在登录页输入令牌后即可查看/编辑,建议「添加到主屏幕」。主屏幕上的网页 App 和 Safari 不共享登录状态,第一次打开时要再登录一次。
