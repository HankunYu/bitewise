# iOS 快捷指令配置

服务地址假设为 `http://192.168.x.x:8600`(替换成本机内网 IP;每个用户一个实例,端口用该用户自己的,见 README)。

## 快捷指令一:拍照记饭

1. 新建快捷指令,命名「记一顿」。
2. 添加操作:**拍照**(或「从相册中选择」,按喜好;可以两个都建)。
3. 添加操作:**要求输入**(文本,提示语"补充说明(可留空)",允许空输入)。
4. 添加操作:**获取 URL 内容**:
   - URL:`http://192.168.x.x:8600/api/upload`
   - 方法:`POST`
   - 请求体:`表单`
   - 表单字段:
     - `image` → 类型「文件」,值选「照片」变量
     - `text` → 类型「文本」,值选「提供的输入」变量
5. (可选)添加操作:**显示通知**,内容随意(如"已提交"),确认上传动作跑完了。

建议把它加到主屏幕小组件或锁屏,拍完即传,识别在服务端后台进行,结果去网页看。

## 快捷指令二:文字记录 / 修正 / 体重

1. 新建快捷指令,命名「记一笔」。
2. 添加操作:**要求输入**(文本)。
3. 添加操作:**获取 URL 内容**,同上,但表单只带 `text` 字段。

这一个入口同时支持三种用法,服务端 AI 自动判断意图:

| 输入示例 | 效果 |
|---|---|
| `午饭吃了一碗牛肉面和一个煎蛋` | 记录一顿饭并估算营养 |
| `刚才那顿改成600大卡` | 修改最近的记录 |
| `删掉上一条` | 删除记录 |
| `体重 72.5` | 记录体重(纯体重格式走快速通道,不调 AI) |

## Dashboard

手机浏览器打开 `http://192.168.x.x:8600` 即可查看/编辑,建议「添加到主屏幕」。
